# 屿阅 v0.1 开源准备需求

状态：confirmed  
Revision：OSS-V0.1-REQ-2026-08-10-R7

## 目标

把现有屿阅收敛为可公开推敲、可直接安装、默认保护隐私的 macOS Markdown 阅读器，使非技术接收者能够可靠查看 AI 生成的 Markdown 文档。

## 用户结果

### R-001 直接安装

用户必须能从 GitHub Releases 下载 unsigned macOS 安装产物，不要求自行构建。Release 必须说明未签名状态、Gatekeeper 安装路径、校验和与从源码构建方法。

### R-002 常见 AI Markdown

阅读器必须支持段落、H1-H6、列表、引用、链接、图片、表格、删除线、任务列表、脚注、GitHub Alerts、代码、KaTeX 和受限 Mermaid。原始 HTML 必须按文本显示，不得执行。

### R-003 长文档阅读

必须提供全文搜索、H1-H4 目录、稳定标题锚点、内部跳转、代码复制/语言标签，并让宽表格和代码块可查看。全文搜索通过 Ctrl/Cmd+F 独立浮窗提供；字体与内容宽度收纳于阅读设置入口；解析或图表超限时必须给出明确提示。

### R-004 桌面文件体验

必须支持原生 File 菜单中的“打开… / Cmd+O”和“导出为 PDF… / Cmd+P”、文件对话框、拖入、`.md/.markdown` 系统关联、多标签、规范路径去重、各标签独立文件刷新和阅读位置保持。PDF 导出只针对当前标签的已净化阅读正文，使用 macOS 原生打印对话框中的“存储为 PDF”，不自动写入文件。打印版式默认使用上 18 mm、左右 16 mm、下 20 mm 页边距；系统“存储为 PDF”面板默认文件名必须是当前 Markdown 文件同名的 `.pdf`（如 `汇报.md` 为 `汇报.pdf`）。

### R-005 隐私默认

本地文档不得上传。文档目录内安全相对图片可自动加载；HTTPS 图片默认阻断，只能在当前标签显式临时授权；关闭标签即撤销。HTTP、file、绝对路径、目录外路径和未知 scheme 不得加载。

### R-006 安全导航

文档内锚点必须留在应用内；外部 HTTP/HTTPS 链接只能在用户明确点击后由系统浏览器打开。文档不得触发其他系统路径或 scheme。

### R-007 可见失败

文件、读取、解析、图片、SVG、Mermaid、外链和容量错误必须可见、可定位且不泄露本机路径。单个失败不得静默清空整篇文档或其他标签。

### R-008 基础阅读体验

必须支持浅色、深色和跟随系统，字体缩放、内容宽度，以及主要控件的键盘操作、可见焦点、语义角色和对话框焦点管理。主题入口必须说明当前模式与下一次切换结果；阅读主区优先让给正文，目录位于左侧，宽版必须使用可用阅读宽度。

### R-009 可维护性

Markdown 必须采用 unified/remark/rehype AST 管线。目录、资源、图表和诊断必须来自类型化结果，不得继续依赖渲染后遍历 DOM 作为事实来源。

### R-010 开源质量

仓库必须包含 MIT License、准确 README、SECURITY、CONTRIBUTING、Code of Conduct、锁文件、CI、测试语料和可复现 Release workflow。生产高危依赖告警必须修复或在发布前有可复核且带期限的非可利用说明。

### R-011 界面语言

应用界面必须支持简体中文、English、繁體中文和日本語。首次启动时按 macOS 系统语言选择（繁中地区映射为繁體中文；英语、日语分别映射；其余语言回退简体中文）；用户在阅读设置中选择后，必须立即生效并仅本地记住该偏好。语言只适用于应用控件、状态、提示和可访问名称，不得翻译或改写 Markdown 正文、代码与图表源内容。

### R-012 品牌标识

应用的显示名称、窗口标题、原生应用菜单、欢迎页、macOS `.app` 与 DMG 名称必须为“屿阅”。应用图标必须从已确认的靛蓝与海绿色文档、海浪与岛屿图形生成，并在 Dock 与 Finder 小尺寸下保持清晰。macOS bundle identifier 必须为 `com.zoulin.yuyue`，以避免与旧的本地 MDReader 构建冲突；`mdreader-image` 协议与本地偏好键继续保留。首个公开版本前无需执行已发布安装的迁移。

## 关键场景

### S-001 打开并阅读

Given 用户选择或拖入支持格式的文件，when 文件有效且未超限，then 创建或激活唯一标签并呈现正文、目录和诊断。

### S-002 重复打开

Given 同一规范文件已经打开，when 用户再次打开它，then 激活已有标签，不创建第二个文档上下文或 watcher。

### S-003 编辑器原子保存

Given 文件由外部编辑器通过临时文件 rename/replace 保存，when 新文件稳定可读，then 相应标签刷新一次、revision 单调增加并尽量保持标题位置。

### S-004 远程图片

Given 文档包含 HTTPS 图片，when 尚未授权，then 不产生该图片网络请求；when 用户在当前标签显式加载，then 只在该标签生命周期加载并使用 no-referrer；when 标签关闭，then 授权消失。

### S-005 恶意内容

Given 文档包含 raw HTML、危险 URL、SVG 外部引用或 Mermaid 网络型内容，when 渲染，then 内容被显示为文本、阻断、净化或报告错误，不得访问越界文件、执行脚本或绕过远程资源授权。

### S-006 长文档异常

Given 文档、AST、资源或图表超过限制，when 处理，then 应用返回稳定诊断并保持其他标签可交互。

### S-007 unsigned 安装

Given 用户下载 GitHub Release，when 校验 SHA-256 并按文档处理 Gatekeeper，then 可以安装运行；文档不得暗示产物经过 Apple 签名或公证。

### S-008 File 菜单

Given 用户已打开 Markdown，when 从 File 选择“打开…”或按 Cmd+O，then 显示受限于支持扩展名的文件选择器；when 选择“导出为 PDF…”或按 Cmd+P，then 仅打印当前标签的阅读正文并打开 macOS 原生打印对话框，用户可选择“存储为 PDF”；打印版式使用上 18 mm、左右 16 mm、下 20 mm 页边距，且保存面板默认文件名为当前 Markdown 的同名 `.pdf`。未打开文档时，导出操作必须给出可理解提示。

### S-009 界面语言

Given 用户首次启动应用且没有既有语言偏好，when 系统语言为英语、日语或繁中地区语言，then 应用使用对应界面语言；when 系统语言不在支持范围内，then 使用简体中文。Given 用户在阅读设置中选择任一支持语言，when 选择完成，then 当前界面立即切换并在下次启动时保持该选择，Markdown 正文不发生翻译。

### S-010 品牌标识

Given 用户启动已打包的应用，when 查看 Dock、Finder、应用窗口、原生应用菜单和欢迎页，then 均显示“屿阅”及一致的靛蓝与海绿色图标；when 安装 DMG，then 挂载卷与应用包名称均为“屿阅”。

## 非范围

- 编辑和保存 Markdown。
- 云服务、账号、遥测、插件和自动更新。
- 整篇 HTML 导出、无对话框的自动/批量 PDF 写入。
- Windows/Linux v0.1 安装包。
- Apple Developer ID 签名和公证。
- 最近文件与跨重启标签恢复。

## 验收基线

- 需求 R-001 至 R-012 均有自动化或真实 macOS 验收入口。
- README、应用行为、Release 说明和事实 Owner 不得互相冲突。
- 只有实际构建、测试、审计和真实运行证据齐全后，才能发布 v0.1。

## 阅读界面补充验收（2026-08-10）

- 顶栏为单行紧凑布局：标签在左，打开文件、主题与阅读设置入口在右；设置使用清晰的 20px 图标，低频阅读控制不常驻占用正文高度。
- Ctrl/Cmd+F 打开独立搜索浮窗，提供全文搜索与匹配切换；按 Enter、点击上下匹配或再次编辑搜索词时输入焦点与字符都不得丢失。阅读设置仅提供字体缩放、舒适/宽版和适用的远程图片临时授权；点击任意面板外区域（包括标题栏、标签栏和正文）关闭面板。
- File 菜单提供“打开… / Cmd+O”和“导出为 PDF… / Cmd+P”；后者仅输出当前阅读正文至 macOS 原生打印对话框，用户可在该对话框中选择“存储为 PDF”。
- 代码块复制使用图标按钮，并提供“复制代码”的可访问名称和成功反馈。
- 正文滚动条不常驻占位，悬停或滚动时保持可辨识且可操作；表格、代码与公式等横向可滚动区悬停时显示对应滚动条；长文档目录固定在左侧。
- Mermaid 与本地 SVG 在通过既有安全边界后，中文/文字内容可见；大图预览的图片画布在可视区域垂直居中，上下留白对称。
- 阅读设置提供语言选择：简体中文、English、繁體中文、日本語。首次启动按 macOS 系统语言选择，用户选择后仅在本机保存偏好；切换即时生效，Markdown 正文、代码和图表源内容保持原样。
