# 屿阅 macOS Release

This release is an unsigned macOS build. It is not signed with an Apple Developer ID and is not notarized by Apple.

## Verify the download

Download the `.dmg` and `SHA256SUMS` files from this release, then run:

```bash
shasum -a 256 -c SHA256SUMS
```

Only continue when the checksum for the downloaded DMG reports `OK`.

## Install on macOS

1. Open the verified DMG and drag 屿阅 to Applications.
2. Open 屿阅 once. macOS may show a Gatekeeper warning because this build is unsigned.
3. If macOS blocks the app, open **System Settings → Privacy & Security**, review the blocked-app message, and choose **Open Anyway** only after verifying the checksum.
4. Confirm the application name and publisher prompt, then open it from Applications.

The application reads Markdown files locally. HTTPS images remain blocked until explicitly allowed for the current tab; the authorization is discarded when that tab closes.

The attached build provenance is generated by GitHub Actions for the tagged source revision. To build from source, see the repository README and run `npm ci`, `npm run tauri -- build --bundles app --ci --no-sign`, followed by `bash scripts/build-unsigned-dmg.sh` on macOS. The DMG step intentionally skips Finder automation so it also works in non-GUI CI sessions.

The DMG filename architecture is derived from the bundled Mach-O executable (`arm64`, `x86_64`, or `universal2`), not from the host process architecture.
